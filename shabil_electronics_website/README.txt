HOW TO PREVIEW
Open index.html in a modern browser. All pages use relative paths and can be
tested locally without a build tool or framework.

PUBLISHING
Upload the contents of this folder to a GitHub repository. In repository
Settings > Pages, publish from the main branch and /(root).

IMPORTANT ACCURACY NOTES
- Product images are generated illustrative assets, not verified stock.
- No real product prices, opening hours, establishment year, business history,
  social accounts or exact map pin were supplied.
- The enquiry form validates in the browser and opens the visitor's email app
  using a mailto link. This static site does not store or transmit form data.
- The map is an address search, not a verified exact business pin.
- The media audio is an original short demonstration tone, not a workshop
  recording.

ACADEMIC REQUIREMENTS IMPLEMENTED
Seven linked HTML pages, one shared external CSS file, JavaScript enhancement,
responsive layouts and two breakpoints, image alt text, an eight-plus image
gallery, products/services table with merged cells, HTML5 audio controls,
FAQ using details/summary, contact form with validation, and map iframe.
